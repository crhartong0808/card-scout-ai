Setup Instructions

This package includes a no-install preview and PWA files. For real phone push alerts, upload it to GitHub/Vercel and connect a backend later.

  1. Open index.html to use the simple version.
  2. To install on phone, host online with Vercel or Netlify.
  3. Open the URL on iPhone/iPad Safari → Share → Add to Home Screen.
  4. Connect Supabase later for multi-user accounts and real saved data.
  5. Connect live card data/API later for true automatic deal scans.
