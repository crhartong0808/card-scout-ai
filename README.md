# CardScout AI Clean PWA Preview

## Quick open
Double-click `index.html`. No installs needed.

## Phone / iPad
To add to Home Screen and use real push notifications later, the site must be hosted online with HTTPS.

Recommended path:
1. Upload this folder to GitHub.
2. Deploy it free on Vercel or Netlify.
3. Open the live URL on iPhone/iPad Safari.
4. Tap Share → Add to Home Screen.

## Important
This no-install version has a helpful chatbot and notification test, but true automatic push alerts and AI image recognition require a hosted backend and AI/data APIs.
